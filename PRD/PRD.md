# AI 기반 작업장 안전관리 시스템 PRD

**문서 버전:** v1.0  
**제품 유형:** Physical AI / Industrial Safety  
**제품명:** AI 기반 작업장 안전관리 시스템  
**주요 입력 데이터:** RGB 영상, 열화상 영상 및 온도 데이터  
**주요 출력 행동:** 위험 경고, 관리자 알림, 경광등·부저 제어, 이벤트 기록  
**적용 환경:** 제조공장, 물류센터, 창고 등 산업 작업장

> **제품 정의**  
> 작업장에 설치된 RGB 카메라와 열화상 카메라를 이용하여 작업자의 낙상, 통로 위험물 및 화재·이상 고온 상황을 실시간으로 감지하고, AI가 위험도를 판단하여 관리자 알림과 현장 경고장치를 자동으로 작동시키는 Physical AI 기반 통합 안전관리 시스템이다.

## 1. 문제 정의 (Problem Statement)

### 1.1 현재 문제

제조공장, 물류센터 및 창고에서는 작업자가 지속적으로 이동하고 자재와 장비가 빈번하게 이동하기 때문에 다양한 안전사고가 발생할 수 있다.

대표적인 위험 요소는 다음과 같다.

- 작업자의 미끄러짐, 넘어짐 등 낙상 사고
- 통로에 방치된 박스, 공구, 자재 등으로 인한 걸림 및 충돌 위험
- 설비 및 전기장치의 과열
- 초기 화재 및 연기 발생
- 사고 발생 후 작업자가 장시간 발견되지 않는 상황

이러한 위험은 작업자 안전뿐만 아니라 생산 중단, 설비 손상 및 공정 지연을 발생시켜 기업의 생산성과 품질 안정성에도 영향을 미친다.

### 1.2 기존 방식의 한계

현재 많은 산업 현장에서는 CCTV, 안전관리자 순찰, 화재감지기 등을 사용하여 작업장 안전을 관리하고 있다.

그러나 기존 방식에는 다음과 같은 한계가 있다.

**CCTV 수동 관제**

관리자가 여러 개의 CCTV 화면을 지속적으로 확인해야 하기 때문에 모든 위험상황을 실시간으로 발견하기 어렵다.

**정기 안전 순찰**

순찰 시점 사이에 발생하는 위험요소를 즉시 발견할 수 없다.

**일반 화재감지기**

연기 또는 일정 수준 이상의 열이 발생한 이후에 경보가 작동하기 때문에 설비의 초기 이상 발열 등 화재 전조를 조기에 파악하기 어렵다.

**사고 발생 후 대응 중심**

현재 방식은 위험요소를 사전에 발견하기보다 사고가 발생한 이후 CCTV 영상을 확인하거나 관리자가 현장을 확인하는 경우가 많다.

### 1.3 제품이 제공하는 핵심 가치

본 제품은 작업장의 카메라 영상을 AI가 실시간으로 분석하여 사람이 지속적으로 CCTV를 감시하지 않아도 위험상황을 자동으로 발견하는 것을 목표로 한다.

핵심 가치는 다음과 같다.

- 작업자 낙상사고의 신속한 발견
- 통로 위험물의 조기 제거
- 설비 과열 및 화재의 조기 발견
- 반복적인 CCTV 모니터링 업무 감소
- 위험상황 발생 시 즉각적인 현장 경고
- 사고 데이터 축적을 통한 반복 위험구역 분석
- 생산 중단 및 설비 손실 최소화

### 1.4 왜 AI가 필요한가

단순 센서만으로는 작업자의 자세, 통로에 놓인 물체의 위험성, 화염과 일반 광원의 차이 등 복잡한 상황을 판단하기 어렵다.

AI 비전 기술을 활용하면 다음과 같은 판단이 가능하다.

**낙상 판단**

사람의 신체 관절 위치와 자세 변화를 분석하여 단순히 앉거나 누운 행동과 갑작스러운 낙상을 구분한다.

**위험물 판단**

작업 통로를 사전에 ROI(Region of Interest)로 지정하고 해당 구역에 박스, 공구, 자재 등이 일정 시간 이상 존재하는지를 분석한다.

**화재 판단**

RGB 카메라의 화염·연기 영상과 열화상 카메라의 온도 데이터를 함께 분석하여 단일 센서 사용 시 발생할 수 있는 오탐을 줄인다.

따라서 AI는 단순한 영상 기록을 넘어 실제 작업환경의 상태를 **인식(Perception) → 판단(Decision) → 대응(Action)**으로 연결하는 핵심 역할을 수행한다.

## 2. 사용자 시나리오 (User Scenario)

### 1단계. 시스템 설치

안전관리자는 작업장 주요 구역에 RGB 카메라와 열화상 카메라를 설치한다.

설치 대상 구역은 다음을 우선으로 한다.

- 작업자 주요 이동 통로
- 자재 적재 공간
- 설비 주변
- 화재 위험성이 높은 전기설비 주변
- 물류 이동 구역

관리자는 웹 기반 대시보드에서 카메라 화면에 작업자 통로와 위험구역을 지정한다.

### 2단계. AI 데이터 수집

RGB 카메라는 작업장 영상을 실시간으로 촬영한다.

열화상 카메라는 설비 및 작업환경의 온도 분포를 측정한다.

Edge AI 장치는 카메라 데이터를 실시간으로 수신하며 기본적으로 현장에서 데이터를 처리한다.

### 3단계. AI 분석

AI는 실시간 영상에서 다음 항목을 분석한다.

**작업자 분석**

- 사람 검출
- 작업자 위치 추적
- 자세 변화 분석
- 낙상 여부 분석
- 낙상 이후 움직임 여부 분석

**작업환경 분석**

- 통로 내 물체 검출
- 위험구역 내 물체 방치시간 측정
- 작업자 이동 방해 여부 판단

**화재 분석**

- 화염 검출
- 연기 검출
- 열화상 온도 이상 검출
- 급격한 온도 상승 감지

### 4단계. 위험 판단

시스템은 감지 결과를 기반으로 위험 수준을 분류한다.

| 위험 수준 | 예시 | 시스템 판단 |
|---|---|---|
| Level 0 | 정상 작업 | 정상 |
| Level 1 | 통로에 물체 일시 발생 | 관찰 |
| Level 2 | 통로 위험물 장시간 방치 | 주의 |
| Level 3 | 작업자 낙상 의심 | 위험 |
| Level 4 | 화염 + 고온 동시 감지 | 긴급 |

단일 프레임만으로 위험을 판단하지 않고 일정 시간 동안의 상황 변화를 함께 분석하여 오탐을 감소시킨다.

### 5단계. 자동 대응

위험 수준에 따라 시스템이 자동으로 행동한다.

**통로 위험물**

→ 대시보드 경고  
→ 일정 시간 이상 방치 시 관리자 알림

**작업자 낙상**

→ 현장 경광등 및 부저 작동  
→ 관리자에게 위험 위치 및 카메라 영상 전송

**화재 또는 이상 고온**

→ 현장 경보 작동  
→ 관리자에게 긴급 알림  
→ 이벤트 위치 및 온도 정보 제공

(가정) 향후 외부 PLC 또는 안전제어 시스템과 연동할 경우 특정 설비에 대한 안전 정지 요청 신호를 전달할 수 있다.

### 6단계. 관리자 확인 및 후속 조치

관리자는 PC 대시보드에서 다음 정보를 확인한다.

- 위험 발생 위치
- 위험 유형
- 위험 발생 시간
- 위험 이미지 또는 영상
- 열화상 온도
- 처리 상태

관리자는 현장 확인 후 이벤트를 정상, 오탐 또는 사고로 분류한다.

해당 데이터는 데이터베이스에 저장되어 향후 위험 발생 빈도와 반복 위험구역 분석에 사용된다.

## 3. 성공 지표 (Success Metrics)

초기 목표치는 제한된 제조·물류 작업장 환경에서 운영한다는 조건으로 설정한다. **(가정)**

| KPI | 목표 | 측정 방법 |
|---|---:|---|
| 사람 검출 정확도 | ≥ 97% | 테스트 영상 내 작업자 검출 |
| 낙상 감지 Recall | ≥ 95% | 실제/재현 낙상 데이터 평가 |
| 낙상 오탐률 | ≤ 5% | 정상 행동 대비 오탐 비율 |
| 통로 위험물 검출 Recall | ≥ 95% | 지정 ROI 내 물체 검출 |
| 화염·연기 감지 Recall | ≥ 95% | 화재 테스트 데이터 |
| 이상 고온 감지 성공률 | ≥ 98% | 설정 온도 초과 이벤트 |
| 위험 발생→AI 판단 시간 | ≤ 2초 | 이벤트 발생 시점 기준 |
| 판단→현장 경보 시간 | ≤ 1초 | AI 이벤트 발생 기준 |
| 관리자 알림 전달 시간 | ≤ 5초 | 이벤트 발생 후 알림 수신 |
| 시스템 가동률 | ≥ 99% | 월간 운영 로그 |
| 이벤트 로그 저장률 | ≥ 99.9% | 발생 이벤트 대비 저장 데이터 |
| 반복 위험구역 식별 | 월 1회 이상 리포트 | 이벤트 위치 통계 |

### 핵심 KPI

제품 초기 단계에서 가장 중요한 KPI는 다음 4가지로 정의한다.

1. **낙상 감지 Recall ≥ 95%**
2. **위험상황 오탐률 ≤ 5%**
3. **위험 감지 후 현장 경고까지 3초 이내**
4. **화재·이상 고온 감지 Recall ≥ 95%**

## 4. 기술 스택 (Technology Stack)

| 구성 | 사용 기술 | 선정 이유 |
|---|---|---|
| RGB 카메라 | 1080p IP Camera / USB Camera | 범용성이 높고 객체 및 행동 인식에 충분한 해상도 제공 |
| 열화상 카메라 | FLIR 계열 Thermal Camera 또는 동급 제품 | 비접촉 방식으로 설비 온도 및 이상 고온 감지 가능 |
| 영상 프로토콜 | RTSP / ONVIF | 산업용 IP 카메라에서 널리 사용하는 표준 |
| 보조 센서 | 온도·연기 센서 (선택) | 카메라 AI 판단과 결합하여 화재 오탐 감소 |
| MCU | ESP32 또는 STM32 | 부저·경광등·릴레이 등 현장 장치 제어 |
| Edge AI | NVIDIA Jetson Orin Nano 또는 동급 Edge GPU | 현장에서 실시간 영상 추론 가능, 네트워크 장애 시에도 동작 가능 |
| 객체 인식 모델 | YOLO 계열 Object Detection Model | 사람, 박스, 공구 등 실시간 객체 검출에 적합 |
| 자세 인식 | MediaPipe Pose / Pose Estimation Model | 사람의 관절 위치를 추적하여 낙상 판단 가능 |
| Tracking | ByteTrack 또는 DeepSORT | 작업자 이동 및 일정 시간 행동 추적 |
| 화재 감지 AI | Fire/Smoke Detection CNN 또는 Object Detection Model | 화염·연기 영상 기반 분석 |
| 열 이상 분석 | Thermal Threshold + Temporal Analysis | 절대온도와 온도 상승률을 동시에 분석 가능 |
| 영상 처리 | OpenCV | ROI 설정, 프레임 처리, 영상 전처리 |
| AI Framework | PyTorch | 모델 학습 및 커스텀 모델 구현 용이 |
| Edge 최적화 | TensorRT | NVIDIA Edge 장치에서 추론 속도 향상 |
| 서버 | FastAPI 기반 Backend Server | API 구현이 간단하고 AI 서비스 연동에 적합 |
| 통신 | MQTT / REST API | Edge 장치와 서버 및 MCU 간 이벤트 전달 |
| 데이터베이스 | PostgreSQL | 이벤트, 위치, 시간, 처리 결과 등 구조화 데이터 관리 |
| 영상 저장 | NAS 또는 Object Storage | 위험 이벤트 이미지 및 짧은 영상 저장 |
| 대시보드 | React 기반 Web Dashboard | 카메라·이벤트·통계정보 통합 관리 |
| 알림 | Web Push / SMS / 사내 메신저 API | 위험 수준별 관리자 실시간 알림 |
| 현장 경고 | 경광등 + 부저 + Relay | 인터넷 연결 없이도 즉각적인 물리적 대응 가능 |

## 5. 개발 범위 / 비범위 (Scope)

### 개발 범위 (In Scope)

#### 1. 작업자 실시간 검출

카메라 화면 내 작업자를 실시간으로 인식한다.

#### 2. 작업자 낙상 감지

Pose Estimation과 시간 변화 데이터를 이용하여 갑작스러운 자세 변화와 바닥에 쓰러진 상태를 감지한다.

#### 3. 낙상 후 무반응 감지

낙상 이후 일정 시간 동안 작업자의 위치 변화가 없는 경우 위험도를 상향한다.

#### 4. 작업 통로 위험물 감지

사전에 지정한 작업 통로 ROI 내부에 박스, 공구, 자재 등이 존재하는지 감지한다.

#### 5. 위험물 방치시간 측정

일시적으로 통과하는 물체와 실제 방치된 위험물을 구분하기 위해 지속시간을 측정한다.

#### 6. RGB 기반 화염·연기 감지

영상에서 화염 및 연기 특징을 AI 모델로 감지한다.

#### 7. 열화상 기반 이상 온도 감지

설비의 특정 영역이 지정된 온도를 초과하거나 급격하게 온도가 상승하는 상황을 감지한다.

#### 8. 복합 화재 판단

RGB 영상과 열화상 데이터가 동시에 위험 조건을 만족할 경우 화재 위험도를 상향한다.

#### 9. 현장 경고장치 제어

위험 이벤트 발생 시 MCU에 명령을 전달하여 경광등과 부저를 작동시킨다.

#### 10. 관리자 실시간 알림

위험 유형, 발생 위치, 발생 시간 및 이벤트 이미지를 관리자에게 전달한다.

#### 11. 이벤트 데이터 저장

위험상황별 발생 시간, 위치, 위험 유형, 이미지, 처리 결과를 데이터베이스에 저장한다.

#### 12. 관리자 대시보드

카메라 상태, 위험 이벤트, 통계 및 처리 이력을 웹 화면에서 조회한다.

#### 13. 위험구역 설정

관리자가 카메라 화면에서 감시 대상 통로 및 위험구역을 직접 지정할 수 있도록 한다.

#### 14. 위험 이벤트 통계

구역별 및 시간대별 위험 발생 빈도를 분석한다.

---

### 개발 제외 범위 (Out of Scope)

초기 제품에서는 다음 기능을 개발 범위에서 제외한다.

#### 1. 얼굴인식 및 개인 신원 확인

개인정보 보호 문제를 고려하여 특정 작업자의 신원을 식별하지 않는다.

#### 2. 음성인식

작업자의 음성이나 비명 분석은 초기 버전에서 제외한다.

#### 3. 모바일 네이티브 앱

초기 버전에서는 웹 기반 관리자 페이지와 알림을 사용한다.

#### 4. 완전 자동 소화 시스템

AI가 화재를 판단하여 소화 설비를 직접 작동하는 기능은 안전 인증 문제로 제외한다.

#### 5. AI의 직접적인 설비 강제 정지

초기 제품에서는 경고 및 PLC 안전정지 요청 신호 제공까지만 고려하며 AI 단독 판단에 의한 설비 강제 정지는 제외한다.

#### 6. 작업자 생산성 평가

작업속도, 휴식시간 등을 분석해 작업자를 평가하는 기능은 개발하지 않는다.

#### 7. 모든 종류의 위험물 인식

초기에는 박스, 공구, 자재 등 사전에 정의된 위험물만 지원한다.

#### 8. 전체 공장 Digital Twin 구축

공장 전체에 대한 3D 모델 및 Digital Twin 기능은 포함하지 않는다.

#### 9. 클라우드 기반 실시간 영상 분석

개인정보 및 네트워크 지연을 줄이기 위해 실시간 추론은 Edge 장치에서 수행한다.

투자 회수기간은 다음과 같다.

**Payback Period = 초기 투자비 ÷ 월 순 절감액**

= 35,000,000 ÷ 4,500,000  
= **약 7.8개월**

초기 투자비는 약 3,500만 원으로 예상되나, 안전관리 업무 자동화와 사고 및 생산중단 기대손실 감소를 통해 약 8개월 내 투자비 회수가 가능할 것으로 예상한다.

따라서 단순 CCTV 교체 제품이 아니라 기존 CCTV를 **수동 관찰 장비에서 능동적인 안전 대응 시스템으로 전환하는 제품**으로 포지셔닝한다.

## 제품 핵심 차별점

기존 CCTV는 영상을 **기록**하지만 본 시스템은 영상을 **이해하고 행동한다.**

**기존 CCTV**

카메라 촬영  
→ 영상 저장  
→ 사람이 발견  
→ 사람이 판단  
→ 사람이 대응

**AI 기반 작업장 안전관리 시스템**

카메라·열화상 센싱  
→ AI 실시간 분석  
→ 위험 판단  
→ 현장 경고 및 관리자 알림  
→ 이벤트 자동 기록

이를 통해 안전관리자의 반복적인 모니터링 부담을 줄이고 위험상황에 대한 대응시간을 단축한다.

## 초기 PoC 권장 범위

전체 기능을 동시에 구현하기보다는 개인 프로젝트 단계에서는 다음 3가지 핵심 기능을 우선 검증한다.

### PoC 1 — 작업자 낙상 감지

웹캠 + Pose Estimation을 이용하여 정상 보행과 낙상 상태를 구분한다.

**검증 KPI**

- 낙상 Recall ≥ 90%
- 판단시간 ≤ 2초

### PoC 2 — 통로 위험물 감지

카메라 화면에 가상의 작업 통로를 설정하고 박스 등이 일정 시간 이상 방치되는 경우 위험으로 판단한다.

**검증 KPI**

- 위험물 검출률 ≥ 90%
- 방치시간 측정 오차 ±1초

### PoC 3 — 화재·고온 감지

RGB 카메라의 화염 영상 또는 열화상 데이터 중 하나를 이용해 화재 위험 이벤트를 감지한다.

실제 화재를 발생시키는 실험 대신 공개 화재 영상 데이터 및 안전하게 생성된 온도 데이터를 사용한다.

**검증 KPI**

- 화재 위험 감지 Recall ≥ 90%
- 위험 판단시간 ≤ 3초

### PoC 최종 시연

**정상 상태**

카메라  
→ AI 분석  
→ `SAFE`

**작업자 낙상**

카메라  
→ Pose 분석  
→ `FALL DETECTED`  
→ 부저 작동

**통로에 박스 방치**

카메라  
→ 객체 검출  
→ 위험구역 중첩  
→ 일정 시간 경과  
→ `OBSTACLE WARNING`

**고온/화재**

카메라 또는 온도 입력  
→ 위험 기준 초과  
→ `FIRE / HIGH TEMP WARNING`  
→ 경광등 작동

이를 통해 **Perception → Decision → Action**의 Physical AI 구조를 개인 프로젝트 수준에서도 명확하게 시연할 수 있다.
