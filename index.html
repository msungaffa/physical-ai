Problem

사고는 순식간에 나지만,
발견은 늘 늦습니다.

제조공장, 물류센터, 창고에서는 작업자와 자재, 장비가 끊임없이 움직입니다. 낙상, 통로 장애물, 설비 과열 같은 위험은 사람이 CCTV와 순찰로 모두 따라잡기 어렵습니다. 사고 뒤에는 생산 중단과 설비 손상, 공정 지연까지 이어집니다.

1

CCTV 수동 관제

관리자가 여러 화면을 계속 지켜봐야 해서 모든 위험상황을 실시간으로 발견하기 어렵습니다.

2

정기 안전 순찰

순찰과 순찰 사이에 생긴 위험요소는 즉시 알아차릴 수 없습니다.

3

일반 화재감지기

연기나 일정 수준 이상의 열이 나야 울리기 때문에 설비 초기 발열 같은 화재 전조를 놓치기 쉽습니다.

How it works

이렇게 작동합니다

카메라가 보고, AI가 위험도를 판단하고, 현장 장치가 바로 움직입니다. 실시간 분석은 현장의 Edge AI 장치에서 처리해 네트워크 지연과 영상 유출 부담을 줄입니다.

  1. 감지

    RGB 카메라는 작업장 영상을, 열화상 카메라는 설비와 작업환경의 온도 분포를 실시간으로 수집합니다.

    • 작업자 검출·위치 추적
    • 통로 내 물체 검출
    • 화염·연기·온도 이상

  2. 판단

    자세 변화와 방치 시간 같은 시간 흐름을 함께 분석해 위험 수준을 Level 0~4로 분류합니다. 한 장면만 보지 않아 오탐이 줄어듭니다.

    • Pose 분석으로 낙상 판단
    • ROI 내 방치 시간 측정
    • RGB + 열화상 복합 판단

  3. 행동

    위험 수준에 따라 경광등과 부저를 작동시키고, 관리자에게 위치·영상·온도 정보를 알리며 이벤트를 자동 기록합니다.

    • 경광등·부저 즉시 작동
    • 관리자 실시간 알림
    • 이벤트 이미지와 처리 이력 저장

관리자가 현장을 확인한 뒤 이벤트를 정상 · 오탐 · 사고로 분류하면 그 데이터가 쌓여 위험구역 분석과 모델 개선에 쓰입니다.

Risk levels

위험도에 따라 대응이 달라집니다

감지 결과를 다섯 단계로 나누고, 단계마다 알맞은 행동을 자동으로 실행합니다.

  • Level 0정상 작업정상
  • Level 1통로에 물체가 일시적으로 나타남관찰
  • Level 2통로 위험물을 장시간 방치주의 · 대시보드 경고, 일정 시간 후 관리자 알림
  • Level 3작업자 낙상 의심위험 · 경광등·부저 작동, 위치와 영상을 관리자에게 전송
  • Level 4화염과 고온을 동시에 감지긴급 · 현장 경보, 관리자 긴급 알림, 위치·온도 정보 제공

경광등과 부저는 MCU와 릴레이로 직접 제어하므로, 인터넷 연결 없이도 현장에서 즉각적인 물리적 대응이 가능합니다.

Features

주요 기능

  • 작업자 낙상 감지FALL DETECTION

    사람의 관절 위치와 자세 변화를 분석해 단순히 앉거나 눕는 행동과 갑작스러운 낙상을 구분합니다. 낙상 뒤 일정 시간 움직임이 없으면 위험도를 한 단계 높입니다.

  • 통로 위험물 감지OBSTACLE ON PATH

    관리자가 화면에서 작업 통로를 직접 지정하면, 그 안에 박스·공구·자재가 얼마나 오래 있는지 측정합니다. 잠깐 지나가는 물체와 실제로 방치된 위험물을 구분합니다.

  • 화재·이상 고온 감지FIRE & HEAT

    RGB 영상의 화염·연기와 열화상 카메라의 온도 데이터를 함께 분석합니다. 절대 온도와 온도 상승 속도를 모두 보고, 두 조건이 동시에 충족되면 위험도를 높여 오탐을 줄입니다.

  • 현장 경고와 관리자 알림ALERT & ACTION

    경광등·부저를 즉시 작동시키고, 위험 유형·위치·시간·이미지를 웹 푸시, SMS, 사내 메신저로 전달합니다.

  • 관리자 대시보드DASHBOARD

    카메라 상태와 위험 이벤트, 열화상 온도, 처리 이력을 한 화면에서 확인합니다. 구역별·시간대별 발생 빈도를 분석해 반복 위험구역을 찾아냅니다.

Proof of concept

세 가지 핵심 기능부터 검증합니다

개인 프로젝트 단계에서는 전체 기능을 한꺼번에 만들지 않고, 감지와 판단, 행동의 흐름이 보이는 세 가지를 먼저 시연합니다.

  1. PoC 1

    작업자 낙상 감지

    웹캠과 Pose Estimation으로 정상 보행과 낙상 상태를 구분합니다. 감지되면 FALL DETECTED가 표시되고 부저가 울립니다.

    목표: Recall ≥ 90%, 판단시간 ≤ 2초
  2. PoC 2

    통로 위험물 감지

    화면에 가상의 작업 통로를 설정하고, 박스가 일정 시간 이상 방치되면 OBSTACLE WARNING을 띄웁니다.

    목표: 검출률 ≥ 90%, 방치시간 오차 ±1초
  3. PoC 3

    화재·고온 감지

    공개 화재 영상과 안전하게 만든 온도 데이터로 검증합니다. 기준을 넘으면 FIRE / HIGH TEMP WARNING과 함께 경광등이 켜집니다.

    목표: Recall ≥ 90%, 판단시간 ≤ 3초
