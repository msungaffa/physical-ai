### 2-3. 조도 균일성

💡 명암 차가 크면 전역 히스토그램 평활화 대신 국부 적응형(CLAHE) 처리가 적합합니다.

### 2-4. 역광 / 직사광 유입

## 4. 카메라 / 센서 설치 조건

### 4-1. 카메라 종류 (복수)
[ ] 고정형 CCTV  [ ] PTZ  [ ] 바디캠/헬멧캠  [ ] 드론  [ ] 로봇 탑재  [ ] 차량(중장비) 탑재

💡 이동형 카메라는 시점 변화가 커서 원근 변환 증강과 안정화 처리 범위가 넓어집니다.

### 4-2. 해상도
[ ] 720p 이하  [ ] 1080p  [ ] 2K~4K  [ ] 모름(확인 필요)

💡 입력 해상도는 리사이즈 비율과 소형 객체 정보 손실 정도를 결정해 타일링 필요성을 판단합니다.

### 4-3. 프레임 레이트
[ ] 5fps 이하  [ ] 10~15fps  [ ] 25~30fps  [ ] 60fps 이상

💡 프레임 샘플링 간격과 시계열(행동 인식) 모델의 입력 클립 길이 설정에 사용됩니다.

### 4-4. 설치 높이
[ ] 2m 이하  [ ] 2~4m  [ ] 4~8m  [ ] 8m 이상

💡 높이에 따라 객체의 겉보기 크기와 형태가 변해 앵커 박스 크기와 스케일 증강 범위가 달라집니다.

### 4-5. 촬영 각도
[ ] 수평(정면)  [ ] 사선(30~60°)  [ ] 수직 하향(Top-view)  [ ] 혼합

💡 Top-view는 사람 형태가 일반 데이터셋과 달라 사전학습 모델 전이 시 회전 증강과 추가 라벨링이 필요합니다.

### 4-6. 렌즈 유형
[ ] 일반  [ ] 광각  [ ] 어안(Fisheye)  [ ] 모름

💡 광각·어안 렌즈는 왜곡 보정(Undistortion) 여부를 결정하며, 위험구역 좌표 매핑 정확도에 직결됩니다.

### 4-7. 카메라 대수 및 시야 중첩
[ ] 1대  [ ] 2~5대(중첩 없음)  [ ] 2~5대(중첩 있음)  [ ] 6대 이상

💡 다중 카메라는 카메라 간 색상·밝기 정규화와 중복 검출 제거(Cross-camera NMS) 전처리가 필요합니다.

### 4-8. 영상 압축 / 전송 방식
[ ] H.264  [ ] H.265  [ ] MJPEG  [ ] RTSP 스트리밍  [ ] 로컬 녹화만  [ ] 모름

💡 압축률이 높으면 블록 아티팩트가 생겨 디블로킹 필터나 압축 노이즈 증강이 필요합니다.

### 4-9. 추가 센서 (복수, Physical AI 확장)
[ ] 없음  [ ] 열화상  [ ] 깊이(Depth/ToF)  [ ] LiDAR  [ ] 가스 센서  [ ] 웨어러블(IMU)

💡 이종 센서가 있으면 시간 동기화·좌표 정합(Calibration)·센서 융합 전처리 순서를 설계해야 합니다.

# 💬 최종 질문 프롬프트 예시

조사가 끝난 뒤 아래 양식에 체크리스트 결과를 붙여넣어 질문하세요.

```text
[역할]
너는 피지컬 AI, 컴퓨터 비전 및 데이터 전처리 분야의 최고 기술 전문가야.

[배경]
나는 'AI 기반 작업장 안전관리 시스템'을 개발 중이며,
카메라 영상으로 작업장 위험요소 여부를 판단하는 모델을 만들려고 해.
아래는 실제 현장에서 조사한 결과야.

[현장 조사 결과]
(여기에 작성 완료한 체크리스트 전체를 붙여넣기)

[참고 샘플]
(가능하면 대표 장면 사진 2~5장 첨부: 주간/야간, 원거리 작업자, 노이즈 심한 장면 등)

[요청 사항]
위 조사 결과를 근거로 다음을 제시해줘.

1. 현장 문제 진단: 조사 결과에서 모델 성능을 떨어뜨릴 핵심 위험 요인 상위 5개와 그 근거
2. 최적 전처리 파이프라인: 적용할 기법을 '실행 순서대로' 나열하고,
   각 단계마다 (기법명 / 적용 이유 / 추천 파라미터 초기값 / 생략 시 발생할 문제)를 정리
3. 단계 구분:
   - 학습 전용(오프라인) 전처리
   - 학습·추론 공통 전처리
   - 추론 시(실시간) 전처리
   로 나누고, 추론 지연 허용치(조사 결과 10-2) 안에 들어오는지 검토
4. 데이터 증강 전략: 현장 조건을 반영한 증강 기법과 적용 확률/강도
5. 클래스 불균형 대응: 희귀 위험 이벤트에 대한 데이터 확보·샘플링·손실 함수 전략
6. 우선순위 로드맵: 데이터가 부족한 초기 단계 → 데이터가 쌓인 이후 단계로 나눈 적용 계획
7. 추가 확인 필요 사항: 조사 결과만으로 판단이 어려워 현장 재확인이 필요한 항목

[출력 조건]
- 파이프라인은 표 또는 순서도 형태로 보여줘.
- 가능하면 OpenCV / Albumentations 기준의 의사코드(Pseudo-code)를 함께 제시해줘.
- 일반론이 아닌, 반드시 내 조사 결과의 특정 항목(예: "3-1 용접 연기")을 근거로 연결해서 설명해줘.
```
